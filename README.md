# Dynamic Host Configuration Protocol

A Dynamic Host Configuration Protocol lab project consists of 16 computers, switch, and server.

# Lab requirements

This repository provides a full configuration solution for the following tasks:
1. Set up physical cable and connections.
2. Configure PC's, switch, and server.
3. Configure DHCP information on the server.
4. Configure individual computers through DHCP so it receives IP addresses automatically.
5. Verify computers have IP address through command prompt.
6. Verify any computers can ping other computer.
